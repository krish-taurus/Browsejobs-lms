Write the notes in light markdown with these sections:
- **What you will learn today** — 2–3 lines, plain words.
- One `##` section per idea (follow the keywords). For each idea:
  - Explain it in the simplest possible words. Use a real-life analogy
    ("a variable is like a labelled box").
  - Give ONE tiny worked example. If it is code, keep it under 8 lines and
    walk through it line by line ("line 1 does…, line 2 does…").
  - End with **In one line:** a single-sentence recap.
- **Try it yourself** — 2–3 tiny exercises a beginner can attempt right now.
- **Words you learned today** — a mini glossary: each keyword in one simple sentence.

Rules:
- Short sentences. No jargon without explaining it first — assume zero background.
- Do not invent facts. Never say a job or an outcome is guaranteed.
- No hype adjectives. Warm and encouraging, not salesy.
