# Environment Variable Checklist

Fill `apps/api/.env` and `apps/web/.env` from each app's `.env.example`. **Never commit `.env`.**
`Secret?` = a value to obtain from the provider and rotate into the server's secret store before launch
(§10 item 1). Everything else is a plain config value.

---

## `apps/api/.env`

### Core app
| Key | Secret? | Set to |
|-----|:---:|--------|
| `APP_ENV` | | `production` (or `staging`) |
| `APP_DEBUG` | | `false` in production |
| `APP_KEY` | ✅ | generated by `php artisan key:generate` |
| `APP_URL` | | `https://api.browsejobs.ai` |
| `FRONTEND_URL` | | `https://browsejobs.ai` |
| `APP_TIMEZONE` | | `Asia/Kolkata` |
| `DEFAULT_TENANT_SLUG` | | `browsejobs` |

### Auth / session (must be right or login breaks)
| Key | Set to |
|-----|--------|
| `SESSION_DOMAIN` | `.browsejobs.ai` (leading dot — shares the cookie between api + web) |
| `SANCTUM_STATEFUL_DOMAINS` | `browsejobs.ai,www.browsejobs.ai` |
| `FRONTEND_ORIGINS` | `https://browsejobs.ai,https://www.browsejobs.ai` |

### Database (MySQL 8)
`DB_CONNECTION=mysql` · `DB_HOST` · `DB_PORT=3306` · `DB_DATABASE` · `DB_USERNAME` · `DB_PASSWORD` ✅

### Redis + queue/cache/session (all Redis in prod)
`REDIS_CLIENT=phpredis` · `REDIS_HOST` · `REDIS_PORT=6379` · `REDIS_PASSWORD` ✅ (if the server requires
one) · `QUEUE_CONNECTION=redis` · `CACHE_STORE=redis` · `SESSION_DRIVER=redis`

### Object storage (S3-compatible — recordings, CVs, certificates)
`FILESYSTEM_DISK=s3` · `AWS_ACCESS_KEY_ID` ✅ · `AWS_SECRET_ACCESS_KEY` ✅ · `AWS_DEFAULT_REGION`
(`ap-south-1`) · `AWS_BUCKET` · `AWS_ENDPOINT` (blank for AWS; set for MinIO/Spaces) ·
`AWS_USE_PATH_STYLE_ENDPOINT` (`true` for MinIO)

### Mail (SMTP)
`MAIL_MAILER=smtp` · `MAIL_HOST` · `MAIL_PORT` · `MAIL_USERNAME` ✅ · `MAIL_PASSWORD` ✅ ·
`MAIL_ENCRYPTION` · `MAIL_FROM_ADDRESS` (`hello@browsejobs.ai`) · `MAIL_FROM_NAME` (`BrowseJobs`)

### AI provider (pick one via `AI_PROVIDER`)
| Key | Secret? | Notes |
|-----|:---:|-------|
| `AI_PROVIDER` | | `anthropic` \| `openai` \| … |
| `AI_DAILY_TOKEN_BUDGET_PER_STUDENT` | | e.g. `50000` (rate cap per student) |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | ✅ | if provider = anthropic |
| `OPENAI_API_KEY` / `OPENAI_MODEL` | ✅ | if provider = openai-compatible |

> Integration keys can also be set later in the in-app **Settings** UI (super-admin) — those are
> encrypted at rest and override these env values.

### Payments — Razorpay
`RAZORPAY_KEY_ID` ✅ · `RAZORPAY_KEY_SECRET` ✅ · `RAZORPAY_WEBHOOK_SECRET` ✅
→ webhook URL: `https://api.browsejobs.ai/api/v1/webhooks/razorpay`

### Live classes — Zoom (Server-to-Server OAuth)
`ZOOM_ACCOUNT_ID` ✅ · `ZOOM_CLIENT_ID` ✅ · `ZOOM_CLIENT_SECRET` ✅ · `ZOOM_WEBHOOK_SECRET_TOKEN` ✅
→ webhook URL: `https://api.browsejobs.ai/api/v1/webhooks/zoom`

### Messaging — WhatsApp Cloud API
`WHATSAPP_PHONE_NUMBER_ID` · `WHATSAPP_BUSINESS_ACCOUNT_ID` · `WHATSAPP_ACCESS_TOKEN` ✅ ·
`WHATSAPP_WEBHOOK_VERIFY_TOKEN` ✅ · `WHATSAPP_APP_SECRET` ✅ · `WHATSAPP_TENANT_SLUG` (`browsejobs`)
→ webhook URL: `https://api.browsejobs.ai/api/v1/webhooks/whatsapp`

### Lead capture — Meta Lead Ads
`META_LEAD_WEBHOOK_VERIFY_TOKEN` ✅ · `META_APP_SECRET` ✅ · `META_TENANT_SLUG` (`browsejobs`)
→ webhook URL: `https://api.browsejobs.ai/api/v1/webhooks/meta-lead`

### Optional integrations (only if the feature is used)
- **Voice mocks — Vapi:** `VAPI_API_KEY` ✅ · `VAPI_WEBHOOK_SECRET` ✅ (blank = voice mocks disabled)
- **Google sign-in / Calendar:** `GOOGLE_CLIENT_ID` · `GOOGLE_CLIENT_SECRET` ✅ · `GOOGLE_REDIRECT_URI`
  · `GOOGLE_CALENDAR_CLIENT_ID` · `GOOGLE_CALENDAR_CLIENT_SECRET` ✅
- **Coding labs — Judge0:** `JUDGE0_URL` · `JUDGE0_AUTH_TOKEN` ✅ (the Judge0 service from
  `docker/docker-compose.yml`)
- **DPDP:** `DPDP_CONSENT_VERSION` (`v1`; bump when the privacy policy changes)

## `apps/web/.env`

| Key | Set to |
|-----|--------|
| `NEXT_PUBLIC_API_URL` | `https://api.browsejobs.ai/api/v1` |
| `NEXT_PUBLIC_SITE_URL` | `https://browsejobs.ai` |
| `NEXT_PUBLIC_DEFAULT_TENANT` | `browsejobs` |
| `REVALIDATE_SECRET` ✅ | a random string (on-demand ISR revalidation) |

> `NEXT_PUBLIC_*` values are **baked in at build time** — rebuild the web app (`npm run build`) after
> changing them.

---

## Pre-launch key rotation (§10 item 1)
Rotate and set fresh in the secret store — never reuse anything pasted in a chat:
`APP_KEY` · DB password · Redis password · `AWS_*` · mail creds · AI provider key · all Razorpay ·
all Zoom · all WhatsApp · Meta secrets · Vapi · Google secrets · `JUDGE0_AUTH_TOKEN` · `REVALIDATE_SECRET`.
